# Open Design Discussions

The documents in this directory capture proposals that may be useful for future Emergency Spells V2 discussions. Their presence does not establish an approved design, mandatory follow-up, roadmap commitment, implementation priority, owner, deployment prerequisite, or audit requirement.

Each proposal still requires separate engineering and operational discussion before adoption. If a proposal is adopted, it should receive an explicit scope, owner, review boundary, and implementation decision.

Within these documents, terms such as “should,” “must,” “prerequisite,” and “acceptance criteria” describe the internal constraints of a candidate approach. They do not make the approach itself mandatory.
